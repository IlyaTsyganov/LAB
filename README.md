# LAB

**A simpler way to practice DOOM Eternal.**

LAB is a free Windows tool for DOOM Eternal that helps you track movement, fix common annoyances and adjust the in-game display for speedrunning practice.

Everything in one compact, customizable interface.

[**Download Latest Release**](https://github.com/IlyaTsyganov/LAB/releases/latest) • [**Report an Issue**](https://github.com/IlyaTsyganov/LAB/issues)

![LAB interface](docs/interface.png)

## Features

- **Speedometers** — Track horizontal speed, landing speed and vertical movement directly in the game.
- **Customizable HUD** — Choose the position, size and color of each speedometer.
- **Lighting Fix** — Correct lighting issues in supported early versions of the game on NVIDIA graphics cards.
- **Q/E + Modbot Fix** — Prevent held Q or E keys from repeatedly switching weapon tabs when opening a Modbot.
- **Red Screen Opacity** — Adjust the intensity of the red screen effect at low health.
- **Cleaner Performance Display** — Hide the driver line and hardware labels while keeping useful performance information.

LAB supports multiple versions of DOOM Eternal. Feature availability may vary depending on the game version and hardware.

## Download & Installation

1. Download `LAB.zip` from the [Releases page](https://github.com/IlyaTsyganov/LAB/releases/latest).
2. Extract the entire archive and keep all included files together.
3. Open the extracted `LAB` folder and run `LAB.exe`.
4. Select `DOOMEternalx64vk.exe`, choose your settings and click **Launch game**.

**Requirements:** Windows 64-bit, .NET 10 Desktop Runtime (x64) and Microsoft Edge WebView2 Runtime.

Keep LAB open while playing. If the game is already running outside LAB, close it and launch it through LAB so its features can work.

Your preferences are saved automatically.
