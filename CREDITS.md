# LAB attribution

LAB derives selected native HUD, tint, input protection, metadata and telemetry code from [DESRU-Enhanced](https://github.com/IlyaTsyganov/DESRU-Enhanced) by IlyaTsyganov and the original DESRU by bowsr. Source is GPL-3.0. The Vulkan lighting barrier correction is adapted from billymooreq (MIT; included). Native game font and layout reflection references originate in meath00k by brongo and contributors; no meath00k DLL or cheat/trainer features are bundled.

The original Eternal typefaces and logo remain property of their owners. LAB is unofficial and is not endorsed by id Software or Bethesda. WebView2 retains its included notices.

The LAB 1.0.2 patch profiles, launch ownership and metrics/cvar improvements are ported from [LAB Plus 0.8.21](https://github.com/IlyaTsyganov/LAB-Plus/tree/v0.8.21), retaining separate LAB branding, commands, runtime identifiers and preferences.
